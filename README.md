
# Nền tảng Quản lý Thành viên & Thi Ảo
Trang web đơn giản nhưng mạnh mẽ cho admin & thành viên. Không cần server.

## Tài khoản
- Admin: admin@admin.com / admin123
- Thành viên: do admin tạo (dùng email để đăng nhập)

## Tính năng
- Quản lý tài khoản thành viên
- Tải lên tài liệu
- Tạo phòng thi ảo
- Giao diện đẹp, dễ triển khai GitHub Pages

## Hướng dẫn triển khai
1. Giải nén file ZIP
2. Tạo repo GitHub
3. Upload file lên repo
4. Bật GitHub Pages → Source: `main` branch, `/root`
